## About me

👋 Hi, I'm Boris Leclere, a passionate software craftsman and freelance CTO/Tech Lead.

🔧 I specialize in custom Python & C# development: scripts, bots, internal tools, libraries, and console applications. I love automating workflows, integrating APIs, and building robust solutions for data processing and business needs.

🎯 **What I offer:**
- 🐍 **Custom Python & C# development:** Scripts, bots, internal tools, libraries, automation, API integration, data transformation.
- 🏗️ **Software architecture & tooling:** Design or refactoring of robust solutions (desktop apps, business tools, services), modular development, project structuring, industrialization of deliverables.
- 📦 **Dockerization & CI/CD:** Containerization with Docker & Docker Compose, automated testing, continuous deployment with GitHub Actions, monitoring with Portainer.
- 👨‍💻 **Freelance CTO / External Tech Lead:** Strategic and technical guidance, architecture choices, technical mentoring, code audits, product roadmap.

🚀 **Specialties:**  
C# .NET, Python, console applications, internal libraries, automation, Docker, GitHub Actions, scripting, AI-driven development, mobile & embedded systems.
